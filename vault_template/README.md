# 내 LLM Wiki

Obsidian에서 **폴더를 보관소로 열기**로 이 폴더를 열면 됩니다.

## 매일 하는 일
1. 아침 메일에서 읽을 논문의 **📥 위키 후보로**를 눌러 그대로 보내거나, `inbox/alerts/오늘날짜.md`에서 체크박스를 `[x]`로 바꿉니다.
2. 다음 날 아침이면 `wiki/sources/`에 논문 페이지가 생깁니다. 메일 맨 위 한 줄에 결과가 나옵니다.
3. 마음에 드는 논문은 **✍️ Contribution, ⚠️ Caveats, 🧭 내 연구와의 관계**를 직접 고쳐 쓰고 `<!-- llm-draft … -->` 줄을 지웁니다.

## PDF가 있으면
학교 도서관에서 받은 PDF를 **다운로드 폴더에 그대로 두면** 다음 아침 자동으로 연결되어 본문 기준으로 다시 씁니다. (또는 `raw/pdf/인용키.pdf`로 넣기)

- 그래프 보기(왼쪽 아이콘): 논문·개념 연결
